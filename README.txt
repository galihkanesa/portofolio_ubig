# Portfolio Galih Tegar As'abiman

Website portfolio responsive dengan gaya dark-modern yang terinspirasi dari layout screenshot referensi, tetapi dibuat dengan struktur, warna, komposisi, dan elemen yang berbeda.

## File
- `index.html` — struktur halaman
- `style.css` — desain dan responsive
- `script.js` — interaksi menu dan tahun footer

## Cara menjalankan
1. Buka folder ini di VS Code.
2. Buka `index.html` di browser, atau gunakan extension Live Server.
3. Ganti bagian `emailkamu@example.com` dengan email kamu.
4. Pada bagian foto, kamu bisa mengganti placeholder dengan foto sendiri jika ingin.

## Catatan
Website ini dibuat dari nol dan tidak menyalin kode dari screenshot referensi.
